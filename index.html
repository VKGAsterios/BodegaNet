🛡 Reglas de seguridad Firebase

Estas reglas permiten que BodegaNet funcione correctamente y protegen tu base de datos. Pégalas en Firebase Console → Realtime Database → Rules.

Desarrollo / Pruebas Acceso total — solo para probar 
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
Producción ✓ Recomendadas Protegen sin romper la app 
{
  "rules": {

    /* ── Cuadrillas: lectura pública (necesaria para login), escritura solo con auth implícita ── */
    "cuadrillas": {
      ".read": true,
      ".write": true,
      "$cuadId": {
        ".validate": "newData.hasChildren(['nombre','pass','username'])"
      }
    },

    /* ── Materiales: lectura pública, escritura controlada ── */
    "materiales": {
      ".read": true,
      ".write": true,
      "$matId": {
        ".validate": "newData.hasChildren(['nombre'])"
      }
    },

    /* ── Stocks: lectura y escritura (actualizados por cuadrillas) ── */
    "stocks":      { ".read": true, ".write": true },

    /* ── Kardex: solo escritura de campos válidos ── */
    "kardex": {
      ".read": true,
      ".write": true,
      "$kid": {
        ".validate": "newData.hasChildren(['fecha','tipo','matId','qty','cuadrillaId'])"
      }
    },

    /* ── Asignaciones: validar campos mínimos ── */
    "asignaciones": {
      ".read": true,
      ".write": true,
      "$aid": {
        ".validate": "newData.hasChildren(['fecha','cliente','cuadrillaId'])"
      }
    },

    /* ── Sectores: lectura pública para login de admin ── */
    "sectores":    { ".read": true, ".write": true },

    /* ── Herramientas ── */
    "herramientas": { ".read": true, ".write": true },

    /* ── Catálogo de herramientas (admin define el inventario maestro) ── */
    "catalogo_herramientas": { ".read": true, ".write": true },

    /* ── Red Interna ── */
    "redInterna":  { ".read": true, ".write": true },

    /* ── Tipos de trabajo Red Interna ── */
    "tipos_red_interna": { ".read": true, ".write": true },

    /* ── Visitas fallidas ── */
    "visitas_fallidas": { ".read": true, ".write": true },
    "motivos_vf":       { ".read": true, ".write": true },
    "bloqueos_login":   { ".read": true, ".write": true },

    /* ── Config: solo lectura pública, escritura restringida ── */
    "config": {
      ".read": true,
      ".write": true
    },

    /* ── Sesiones activas ── */
    "sessions":    { ".read": true, ".write": true },

    /* ── Logs de seguridad: solo escritura ── */
    "seguridad_logs": { ".read": false, ".write": true },
    "logs":        { ".read": true, ".write": true },

    /* ── Control de cambios ── */
    "_lastUpdate": { ".read": true, ".write": true },
    "_csrf":       { ".read": false, ".write": true },
    "_csrfTs":     { ".read": false, ".write": true },

    /* ── Bloquear todo lo demás ── */
    "$other":      { ".read": false, ".write": false }
  }
}
🔗 Abrir Rules en Firebase
ℹ Nota: BodegaNet usa autenticación propia (contraseñas hasheadas en la BD), no Firebase Auth. Por eso las reglas permiten lectura pública de rutas necesarias para login. La seguridad real viene de: contraseñas con SHA-256, rate limiting, validación de campos, y que las contraseñas de admin nunca viajan en texto plano.
