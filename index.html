🛡 Reglas de seguridad Firebase

Configura estas reglas en Firebase Console → Realtime Database → Rules para proteger tu base de datos. Nunca uses .read: true, .write: true en producción. 

{
  "rules": {
    "cuadrillas": { ".read": false, ".write": false },
    "materiales": { ".read": false, ".write": false },
    "stocks":     { ".read": false, ".write": false },
    "kardex":     { ".read": false, ".write": false },
    "asignaciones":{ ".read": false, ".write": false },
    "sectores":   { ".read": false, ".write": false },
    "herramientas":{ ".read": false, ".write": false },
    "config":     { ".read": false, ".write": false },
    "seguridad_logs": { ".read": false, ".write": true },
    ".read":  false,
    ".write": false
  }
}

⚠ Nota: estas reglas deshabilitan el acceso público pero requieren Firebase Authentication para acceso real. Mientras migras a Firebase Auth, agrega tu IP a las reglas o usa restricciones de dominio en la consola de Google Cloud.
